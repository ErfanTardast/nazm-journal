# Nazm Roadmap

## MVP
- Discipline OS command center.
- Persistent Review Engine for daily, weekly, mistake, risk, and strategy reviews.
- Trade journal and CSV import with auto-detecting column mapping for foreign broker headers.
- Screenshot attachments on journal entries (client-side downscaled, stored inline).
- Trade plans and pre-trade checklist.
- Strategy/playbook management.
- Performance analytics and risk discipline.
- Visual performance breakdowns by strategy, setup, session, market, symbol, mistake, and emotion.
- Bilingual news/context analysis with local fallback.
- AI coaching and learning mode with local fallback.
- Simple admin, feature flags, provider status, audit logs.

## Next
- CSV import presets for common broker/export formats, kept read-only.
- Pricing unlock path for existing `free` / `pro` / `elite` entitlements.
- Saved sprint progress on the dashboard and review screens.

## Later
- Team/private workspaces.
- Read-only broker/export integrations for import only.
- Additional import/export adapters.
- More advanced strategy review workflows.
